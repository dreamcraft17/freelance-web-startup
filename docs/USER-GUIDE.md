Panduan singkat untuk **client** dan **freelancer**. Staff: [ADMIN-GUIDE.md](./ADMIN-GUIDE.md).

---

## Mulai

1. Buka situs → default bahasa **Indonesia** (`/id`). Ganti EN/ID dari switcher.
2. Browse Jobs / Freelancers tanpa akun.
3. **Daftar** atau **Masuk** saat ingin post job, kirim proposal, chat, atau simpan favorit.
4. Setelah login Anda diarahkan ke dashboard role (`/client` atau `/freelancer`).

---

## Untuk klien

| Langkah | Di mana |
|---------|---------|
| Lihat ringkasan & checklist aktivasi | `/client` |
| Buat lowongan | `/client/jobs/new` |
| Kelola lowongan + filter “perlu review” | `/client/jobs` |
| Bandingkan proposal → chat → shortlist/terima | Detail job (owner) |
| Pesan terikat job | `/messages` |
| Simpan freelancer | Tombol save di profil publik → Settings |
| Laporkan konten mencurigakan | Tombol laporkan di job/profil/proposal/pesan |

**Tips:** Isi brief jelas (scope, budget, mode kerja, lokasi). Budget pakai IDR atau USD sesuai pilihan di form — bukan konversi otomatis dari bahasa UI.

---

## Untuk freelancer

| Langkah | Di mana |
|---------|---------|
| Lengkapi profil publik | `/freelancer/profile` |
| Cari lowongan | `/jobs` atau `/freelancer` → browse |
| Filter nearby / remote | Filter board + `/search/nearby` |
| Kirim proposal | Panel di detail job |
| Lacak proposal | `/freelancer/proposals` |
| Balas klien | `/messages` |
| Ajukan verifikasi (jika tersedia) | Alur verification di app |

**Tips:** Draft proposal tersimpan lokal di browser sampai berhasil dikirim. Proposal memulai diskusi — bukan kontrak instan.

---

## Pesan & notifikasi

- Setiap percakapan idealnya terikat **satu job** agar konteks hiring jelas.
- Notifikasi: proposal, pesan, update kontrak, verifikasi — filter chip All / Proposals / Messages / Contracts.
- Badge unread di navbar = data nyata, bukan angka dekoratif.

---

## Bahasa & mata uang

- Bahasa UI: cookie preferensi + path `/en` atau `/id`.
- Mata uang angka mengikuti **data job** (`IDR`/`USD`); ganti bahasa hanya mengubah format angka.

---

## Keamanan akun

- Jangan bagikan password.
- Logout dari menu akun setelah memakai perangkat bersama.
- Jika akun di-suspend, gunakan alur **appeal** (jika ditawarkan di UI) atau hubungi support.
